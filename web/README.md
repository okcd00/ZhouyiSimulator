# 蓍境 · 一念一卦

基于 `src/蓍草卜卦.py` 的本地沉浸式网页体验。原 Python 文件保持原样。

## 打开

可以直接双击 `web/index.html`（所有资产均为本地文件，不需要网络）。推荐使用 Node.js 启动，以获得稳定的本地存储：

```powershell
node D:\Github\ZhouyiSimulator\web\serve.cjs
```

访问 http://127.0.0.1:4173 。服务器只监听本机。关闭终端或 Ctrl+C 停止。

## 体验

- 写下所问，净心启筮；也可以不填写。
- 备五十五、去六取四十九；每爻重新备蓍。
- 每变依次分二、挂一、揲四、归奇、合蓍，三变生爻，十八变成卦。
- 滑杆自由选择分堆位置；自动模式按原程序范围随机分堆。
- 六、七、八、九分别为老阴、少阳、少阴、老阳；老阴、老阳变爻。
- 右上角“音境”开启原创程序合成五声音阶音乐与动作音效，浏览器需要用户手势才能播放。无需音频服务或 API 密钥。
- 成卦显示本卦、之卦、动爻与原项目《易经》经文。
- 最近 30 次卦笺保存在浏览器 localStorage；可导出含十八变细节的文本。
- 支持键盘、窄屏布局、系统减少动画偏好。

## 实现与校验

`engine.js` 是无 UI 的数量算法，沿用原项目分堆区间 `[1, total-2]` 与余零取四规则，不用直接抽取爻值替代三变。随机数采用浏览器 crypto 与拒绝采样。本实现不会宣称其均匀分堆产生的概率严格等于经典概率模型。

`import-data.cjs` 从 references 导入 64 卦及全文，修正第八卦目录键 `坎上下坤` 为 `坎上坤下`，不修改原始资料。解读显示原文，不生成吉凶预测。

```powershell
node web/import-data.cjs
node web/test.cjs
```

测试穷举 67,996 条合法三变路径，检查去策规则、策数守恒、最终爻值，覆盖 64 卦映射与动爻翻转。

## 资产

`assets/sanctuary.png`：内置 imagegen 生成的原创月下山水游戏背景。最终提示词记录于 `assets/prompt.txt`。

音乐由 `app.js` Web Audio 合成：五声音阶旋律、低音与谐波衰减拨弦音色。它是实时程序音乐，没有预录音频文件。

页面无需安装 npm 依赖、字体或联网资源。应用、音乐、动画均在浏览器本地运行。

保存卦笺支持 TXT 与 PNG 两种格式。PNG 在本机 Canvas 绘制，宽 1200 像素，高度随内容自动增长，包含所问、日期、本卦与之卦图形、卦辞和动爻；支持先预览再下载。
